# X-ray question banks: clinician review

Status: written by Claude on 2026-10-12 and marked approved because Friend decided on 2026-10-12 that clinician review no longer gates release; no clinician has read these items yet, so a reviewer can change any row here and in the JSON. Views are digitally reconstructed radiographs (DRRs) computed in the browser from the TotalSegmentator CT studies (`assets/volumes/<study>/`, CC BY 4.0); they are teaching simulations, not patient films. Banks: `assets/questions/xray-chest.json` and `assets/questions/xray-abdomen.json`. Regenerate checks with `python3 tools/check_questions.py assets/questions/xray-*.json`.
